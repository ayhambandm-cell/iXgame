# iXGAME.io — Custom UI Pack

This pack customizes the original RAW GAME PS4 WebKit host visually while leaving
the routing/chain logic in `index.html` intact.

## Install
1. Start with a copy/fork of:
   https://github.com/rawgame4/rawgame4.github.io/
2. Replace its `index.html` with the `index.html` in this pack.
3. Add `ixgame-banner.png` to the repository root.
4. Replace/update `cache.appcache` with the included version.
5. Keep the original exploit/chain files, payload, patches, and LICENSE intact.
